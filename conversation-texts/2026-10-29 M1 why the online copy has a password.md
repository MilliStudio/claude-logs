### Claude · 2026-10-29 15:42

It doesn't strictly need one. Nothing technical requires a password. It was a choice to keep an unreleased game private. My reasons for keeping it:

1. **Anyone with the link could play it and read its code.** A web game sends all of its code to the browser. Without the password, anyone the link reaches gets every mechanic: the round world, Lantern Pods, the tally, delivery and Awaken. Copyright doesn't protect game ideas, only the actual code and art, so keeping them unseen until release is the main protection you have.
2. **Links travel.** Mattias or Jousef might forward it or paste it in a chat that someone else can see. The site already asks search engines to stay away, but that's only a request. It doesn't stop anyone who has the link.
3. **First impressions.** The trial uses test colours and a test layout. If it got around, strangers would judge Tessera by a rough test build.

What it costs: each tester types the password once, and the browser remembers it.

My recommendation is to keep it. If you ever want a public demo, make a separate copy for that and leave this one private.
