A record entry in document_entries can point to any record table; the diagram shows features as the example. names has no stored link: the app finds {label} in the text.

Version fields

Every table marked "version table" below also has these fields. A save adds a row; no row is ever changed or removed, which is what makes the history. Foreign keys point to id, so they always reach the current version.

FieldTypeKeyHolds
row_idINTEGERPKthis version row
idTEXTthe record's stable ID, shared by all its versions (record_id in the code)
versionINTEGER1, 2, 3 … unique together with id
stateTEXTactive or deleted
saved_atTEXTdate and time of the save
changeTEXTcreate, edit, delete, restore, name-renamed or file-import
changedTEXTwhich fields changed
noteTEXTexplanation for restores, renames and imports
